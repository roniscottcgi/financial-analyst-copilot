# SQL Metadata Pack 01-06
# Document Metadata 07

This pack contains the metadata workbook/dictionary for the 10-table sample MySQL schema.

Included files:
- `01_table_definitions.md` — business purpose, grain, keys, and table-level usage
- `02_column_definitions.md` — column-level metadata for all 10 tables
- `03_join_rules.md` — recommended join rules and business meaning
- `04_example_business_questions.md` — example questions by use case
- `05_quick_start_for_participants.md` — how to use the metadata with SQL/RAG/text-to-SQL
- `06_recommended_vector_loading_pattern` — how to load metadata into your vector store
- `07_recommended_document_vector_loading_pattern` -load the sample document set into a vector store

This is intended to reduce ambiguity and improve:
- SQL quality
- text-to-SQL quality
- RAG grounding
- consistent business language across participants
- Document Quality
